# TRON 钱包签名快速测试

## ✅ 测试环境已就绪

- ✅ WalletConnect Project ID 已配置
- ✅ SDK 已构建
- ✅ 开发服务器已启动

## 🚀 测试步骤

### 1. 打开测试页面

访问：**http://localhost:5173**（Vite 默认端口）

或者如果配置了其他端口，查看终端输出的实际地址。

### 2. 检测钱包

1. 点击页面上的 **"Detect Wallets"** 按钮
2. 等待检测完成
3. 查看是否显示 **"WalletConnect (Tron)"** 选项

### 3. 连接 WalletConnect Tron

1. 找到 **"WalletConnect (Tron)"** 选项
2. 点击 **"Connect"** 按钮
3. **会自动弹出二维码**（WalletConnect SDK 自动生成）
4. 使用支持 WalletConnect 的 TRON 钱包扫描二维码：
   - **推荐钱包**: TokenPocket
   - 其他支持 WalletConnect 的 TRON 钱包也可以

### 4. 测试签名消息

1. 在 **"Message to Sign"** 输入框中输入消息，例如：
   ```
   Hello TRON from Enclave SDK!
   ```
2. 点击 **"Sign Message"** 按钮
3. 在钱包中确认签名
4. 查看签名结果（应该显示一个 hex 字符串）

### 5. 验证结果

✅ **连接成功标志**：
- 显示 TRON 地址（格式：`T...`，34 个字符）
- 显示 Universal Address（格式：`195:T...`）
- Chain ID 显示为 `195`（TRON 主网）

✅ **签名成功标志**：
- 显示签名字符串（hex 格式，以 `0x` 开头）
- 没有错误提示

## ⚠️ 常见问题

### 问题 1: 没有显示 WalletConnect (Tron) 选项

**解决方案**：
- 检查 `.env` 文件中 `VITE_WALLETCONNECT_PROJECT_ID` 是否正确
- 重启开发服务器：`npm run dev`
- 查看浏览器控制台是否有错误

### 问题 2: 扫描二维码后没有反应

**解决方案**：
- 确认设备上已安装支持 WalletConnect 的 TRON 钱包
- 确认钱包应用已打开
- 检查网络连接
- 尝试重新生成二维码（刷新页面）

### 问题 3: 签名失败

**解决方案**：
- 确认钱包已成功连接
- 确认在钱包中点击了"确认"按钮
- 查看浏览器控制台和钱包应用的错误信息
